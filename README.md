# 🎂 Geburtstage

Android-App, die an Geburtstage erinnert.

- Geburtstage selbst eintragen (Jahr optional)
- Übernimmt automatisch Geburtstage aus den Handy-Kontakten
- Übernimmt Geburtstage, die schon im Kalender stehen
- Trägt eigene Geburtstage als jährlichen Termin in den Google-Kalender ein (über das Google-Konto auf dem Handy)
- Erinnert ein paar Tage vorher (Standard: 7 Tage) und am Tag selbst
- Einzelne Geburtstage stummschalten (lange drücken oder über die Benachrichtigung)
- Fotos aus den Kontakten, oder ein eigenes Foto aus der Galerie
- Runde Geburtstage (30, 40, 50 …) werden golden markiert und zusätzlich 30 Tage vorher besonders auffällig angekündigt
- Personen als verstorben markieren: „wäre … geworden“ statt Geburtstags-Erinnerung, auf Wunsch stiller Hinweis am Tag selbst

## APK herunterladen

Jeder Push auf `main` baut automatisch eine neue APK.
Download: **Releases** → neueste Version → `Geburtstage.apk`.

Die App ist immer mit demselben Schlüssel signiert, neue Versionen lassen sich also einfach drüber installieren.
